# OpenAI Codex Usage

## About Me

I work as a **Digital Analyst**, mainly supporting digital marketing and performance campaigns across LATAM markets.

My day-to-day work involves handling data from platforms such as **Google Ads, SA360, CM360, GA4, and SharePoint**, as well as building and maintaining reports using **Excel and Power Query**.

## How I Plan to Use Codex

I plan to use Codex mainly to improve efficiency in repetitive data-processing and automation tasks.

Examples include:

* Creating and debugging **Power Query / Excel automation**
* Processing and combining multiple campaign and performance datasets
* Automating repetitive reporting and data validation tasks
* Checking and improving scripts used for data transformation
* Supporting campaign QA by identifying data inconsistencies or missing values
* Building small internal tools to reduce manual work

## Why I Want to Use Codex

A significant part of my current workflow still involves repetitive manual data processing and QA.

I would like to use Codex to reduce this manual work and spend more time on **performance analysis, identifying insights, and making recommendations**, rather than repeatedly handling the same data-processing steps.

I also want to explore how AI-assisted coding can be practically applied to digital marketing operations, even for users who are not full-time software engineers.

## Expected Outcome

My goal is to gradually automate recurring operational tasks and build reusable workflows that can also be shared with the team.

Ultimately, I expect Codex to help improve:

* Reporting efficiency
* Data accuracy
* QA speed
* Reusability of analysis workflows
* Time available for higher-value analysis
